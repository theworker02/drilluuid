# drilluuid

Drill and reshape uuid text streams with deterministic transforms.

**Site:** https://theworker02.github.io/drilluuid/

## Install / run

```bash
git clone https://github.com/theworker02/drilluuid.git
cd drilluuid
node src/cli.js
node --test
```
